# Numerical Results

This directory contains numerical outputs generated by the evaluation modes in
`patrollingAlgorithms.py`. Environment names are standardized as `Level-1`
through `Level-5` throughout the public dataset.

## Contents

- `path_metrics/`: path-length and multi-metric summaries for the five environments.
- `runtime/full_route/`: full-route timing outputs for each environment.
- `runtime/segment/`: 100-episode route and waypoint-to-waypoint timing records.
- `runtime/`: environment-level and method-level timing summary tables.
- `sensitivity/`: fixed-parameter sweep results for the A* seed ratio and softmin temperature.
- `ablation/`: environment-level ablation records and aggregate summaries.

The JSON files retain detailed numerical records where available. The CSV files
provide analysis-ready summaries. New runs write their outputs to the current
working directory; they do not overwrite this archive unless executed from or
copied into this directory.

Reduced one-episode commands in the repository README are software checks and
should not be interpreted as replacements for the multi-episode datasets here.
